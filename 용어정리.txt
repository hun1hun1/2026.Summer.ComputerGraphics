컨테이너: 데이터를 담는 변수
벡터: 동적배열
이터레이터(Iterator): 주소값의 시작점을 가리킴.

변수(속성): 데이터를 저장하기 위한 이름이 붙은 메모리 공간
ㄴ속성: 객체가 가지고 있는 데이터를 표현할 때 사용하는 개념
함수(동작,이벤트): 특정 작업이나 동작을 수행하기 위해 작성한 코드의 묶음
ㄴ동작: 객체가 수행하는 함수
ㄴ이벤트: 특정 사건이 발생했을 때 실행을 시작하는 진입점

메세지: 한 객체나 시스템이 다른 객체나 시스템에게 특정 동작이나 정보를 전달하기 위한 데이터
콜백구조: 어떤 함수를 다른 함수나 시스템에 전달해 두었다가, 특정 사건이나 조건이 발생했을 때 해당 함수를 다시 호출하는 구조

함수포인터: 함수의 주소값을 저장하는 변수
가상함수포인터: 객체가 자신의 가상함수테이블을 가리키기 위해 가지는 숨겨진 포인터

가상함수테이블: 가상 함수들의 주소를 저장하는 테이블
상속: 기존 클래스의 속성과 동작을 새로운 클래스가 물려받아 사용하는 기능
다형성: 서로 다른 객체가 각자의 방식으로 동작 할 수 있는 특성

핸들러: 특정 이벤트, 메시지, 요청 또는 상황이 발생했을 때 이를 처리하는 코드나 함수를 의미함.
SDK: Software Development Kit, 특정 플랫폼, 운영체제, 서비스 또는 기술을 대상으로 소프트웨어를 개발할 수 있도록 제공되는 개발 도구 모음임.
